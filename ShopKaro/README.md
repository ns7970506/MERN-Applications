🛒 ShopKaro - Full Stack E-Commerce Application
ShopKaro is a full-stack e-commerce web application built using the MERN stack. It provides a complete online shopping experience with user authentication, role-based access control, product management, shopping cart, secure payments, and cloud-based image management.

🚀 Features
👤 User Features
User registration and login
JWT-based authentication
Protected routes
Password hashing using Bcrypt
User profile management
Browse products
Product details
Add products to cart
Update cart quantity
Remove products from cart
Secure checkout
Online payment using Razorpay
Order processing
🔐 Authentication & Authorization
JWT authentication
Protected API routes
Role-based access control
Separate Admin and User permissions
Password encryption using Bcrypt
Authentication middleware
👨‍💼 Admin Features
Admin authentication
Role-based authorization
Product management
Add new products
Update products
Delete products
Manage product information
Manage users
☁️ Media & Payment
Razorpay payment integration
Cloudinary for cloud-based image storage
Multer for handling image uploads
